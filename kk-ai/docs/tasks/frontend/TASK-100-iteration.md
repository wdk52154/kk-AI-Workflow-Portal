## 经验沉淀

### 成功模式

1. **先安装依赖再写代码**：react-router-dom 的安装提前完成，避免了运行时错误
2. **ProLayout + React Router 配合**：使用 `useNavigate` + `useLocation` 实现菜单路由切换，代码简洁
3. **ProTable 的 columns 提取为常量**：符合约束条件，且类型安全
4. **模拟数据直接写在组件内**：避免依赖后端 API，前端独立开发和测试

### 关键实现点

- `menuItemRender` 中使用 `navigate(item.path)` 实现路由跳转
- `ProTable` 的 `columns` 使用 `ProColumns<QuotaProject>` 泛型保证类型安全
- `search: true` 启用内置搜索，`filters` + `onFilter` 启用状态筛选
- `sorter` 实现使用率排序
- `StatusTag` 和 `UsageTag` 子组件封装，提高可读性

### 给团队的建议

> 对于"数据展示型"页面，使用 ProTable + StatisticCard 组合可以快速实现高质量页面。关键是提前定义好数据类型和 API 契约。
